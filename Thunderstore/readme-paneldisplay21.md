# PanelDisplay21 · 全中文属性面板

把游戏里原本藏起来的数值摆到屏幕上，并且全部做成中文。

## 功能

- 右侧属性条：伤害、攻速、暴击率、暴击伤害、生命回复、护甲、移速、跳跃次数、DPS，随装备实时刷新
- 物品数值：鼠标悬停物品图标，看它现在一共给了多少
- buff：图标上显示剩余时间和层数，悬停看名称和说明
- 背包、命令窗、粉碎机的物品自动排序；通关前显示这次传送门会开出哪种；拾取通知可关

界面已经全中文，不用另装汉化。

## 注意

- 别和原版 LookingGlass 同时开，功能重叠
- 0.2.4 起插件标识改名成 `MeowTools21.PanelDisplay21`，从旧版本升级的话，把 `BepInEx/config` 里原来那个面板配置文件改名成 `MeowTools21.PanelDisplay21.cfg`，设置就还在
