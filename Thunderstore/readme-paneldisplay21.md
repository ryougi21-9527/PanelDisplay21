# PanelDisplay21 · 全中文属性面板

把游戏里原本藏起来的数值摆到屏幕上，并且全部做成中文。基于 [Wet-Boys/LookingGlass](https://github.com/Wet-Boys/LookingGlass) 改的。

## 功能

- 右侧属性条：伤害、攻速、暴击率、暴击伤害、生命回复、护甲、移速、跳跃次数、DPS，随装备实时刷新
- 物品数值：鼠标悬停物品图标，看它现在一共给了多少
- buff：图标上显示剩余时间和层数，悬停看名称和说明
- 背包、命令窗、粉碎机的物品自动排序；传送门追踪；未解锁物品提示

界面已经全中文，不用另装汉化。

## 注意

- 别和原版 LookingGlass 同时开，功能重叠
- 插件 GUID 还是 `MeowTools21.PanelDisplay21`，升级不会丢配置
- 想要「面板 + 宝箱高亮 + 小地图」一次装齐，装整合包 [MeowTools21](https://thunderstore.io/c/riskofrain2/p/MeowTools21/MeowTools21/)，别同时装这个
