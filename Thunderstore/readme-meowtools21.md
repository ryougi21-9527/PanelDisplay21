# 21的喵喵工具

一个包装齐三样东西，省得一个个找：

- **[PanelDisplay21](https://thunderstore.io/c/riskofrain2/p/MeowTools21/PanelDisplay21/)** — 全中文属性面板、物品数值、buff 说明、背包排序
- **[QoLChests](https://thunderstore.io/c/riskofrain2/p/Faustvii/QoLChests/)** — 宝箱、神龛、商店终端高亮，空箱隐藏
- **[MiniMapMod](https://thunderstore.io/c/riskofrain2/p/DekuDesu/MiniMapMod/)** — 小地图，M 键开关

面板是独立发版的，它更新了在 mod manager 里单独更新就行，不用等这个包。

## 注意

- 本包不含任何 mod 文件，只是清单，依赖会自动装好
- 别和原版 LookingGlass 一起开，也别再单独装一份 QoLChests 或 MiniMapMod
- 面板已经在这个包里了，别另外再装一次
